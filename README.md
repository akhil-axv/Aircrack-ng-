# Aircrack-ng Notes

A small notes repository containing package-installation references for Aircrack-ng.

## Contents

- `textfile(2).txt`: package manager notes for several Linux distributions.

## Responsible use

Wireless security testing must be limited to networks and equipment you own or have explicit permission to assess. Do not attempt to access someone else's network or credentials.

This repository is an independent notes collection and is not affiliated with the Aircrack-ng project.
